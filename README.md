# PizzaTrack - Sistema de Gestión de Pedidos

## Objetivo

Desarrollar una aplicación en Java que simule el sistema de gestión de pedidos de una pizzería utilizando pilas manuales implementadas con listas ligadas.

El sistema permite:

- Registrar pedidos de pizzas.
- Deshacer pedidos (Undo).
- Rehacer pedidos (Redo).
- Mostrar el pedido actual.
